# pbox

一条命令，在自己的 VPS 上搭好代理节点。默认不需要域名、不需要做选择；想要更多时，进阶选项都在菜单里。全部代码明文开源。

> **当前状态：可以用，尚未公开发布。** 安装、管理、卸载的全流程由自动化流水线在真实的 Ubuntu 虚拟机上反复验证；节点可用性在真实 VPS 上用 v2rayNG 和 FlClash 实测过。仓库目前是私有的，所以下面的在线安装命令暂时不可用，需要把 `dist/pbox.sh` 传到机器上运行。

## 上手

1. 准备一台 VPS（Debian 12+、Ubuntu 22.04+ 或 Alpine），用 SSH 以 root 登录。
2. 运行安装：

   ```bash
   bash pbox.sh install
   ```

3. 一路回车。结束后把屏幕上的链接导入客户端，或开启订阅。

之后随时输入 `pbox` 打开菜单。**连不上时先选"节点体检"**，它会真的经由每个节点访问一次外网，告诉你哪一环有问题。

## 现在有什么

| 功能 | 说明 |
|---|---|
| VLESS-Reality-Vision | 默认主力，不需要域名 |
| Hysteria2 | 默认提速，可开端口跳跃和流量混淆 |
| TUIC、AnyTLS | 可选。TUIC 基于 UDP；AnyTLS 基于 TCP，需要较新的客户端 |
| VLESS-WS-Argo | 经 Cloudflare 隧道，不需要域名、不开放端口；支持临时与固定隧道、优选地址 |
| 订阅 | 推送到你自己的 GitLab 私有仓库，覆盖 v2rayN/NG、Clash 系、sing-box 等客户端 |
| WARP 出口 | 目标网站不欢迎机房 IP 时使用，可按网站分流 |
| 节点体检 | 逐个节点实际走一次连接 |
| 备份恢复、回滚、干净卸载 | 改动失败自动回到上一份可用的配置 |

## 它和别的脚本有什么不同

| | |
|---|---|
| 不用做选择 | 默认方案回车即可；进阶选项收在菜单里，不打扰新手 |
| 会告诉你哪里冲突 | 两个选择互相矛盾时，用人话说明并让你取舍 |
| 体检说的是真话 | 不只看"服务在不在"，而是真的经由节点访问一次外网 |
| 升级不翻车 | 内核版本锁定；新配置先校验，失败自动回滚 |
| 不乱动系统 | 不安装、不替换、不关闭防火墙；内核以专用账号运行，不用 root |
| 不夹带私货 | 没有推广链接，不悄悄屏蔽网站，不依赖作者自己的服务器 |
| 可验证 | 下载的每个程序都核对锁定的哈希；脚本不混淆 |

## 开发

源码在 `src/`，按模块拆分。合并成单文件：

```bash
./build.sh
```

运行不需要 root、不碰系统的测试：

```bash
bash tests/run.sh
```

真机测试会真的安装内核、创建服务和账号，最后卸载。只在可以随时重装的测试机上运行：

```bash
sudo bash tests/vm.sh
```

推送到 GitHub 后，`.github/workflows/ci.yml` 会自动跑三组检查：静态检查与本机测试；在带 systemd 的 Ubuntu 虚拟机（含 ARM）上完整地装一遍再卸掉；在 Debian 和 Alpine 容器里验证下载、哈希和内核对配置的校验。

## 说明

- 名称 pbox 取自 proxy box：一个装好就能用的代理盒子。
- 请遵守你所在地的法律法规和 VPS 服务商的使用条款。
