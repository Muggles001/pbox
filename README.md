# pbox

一条命令，在自己的 VPS 上搭好代理节点。Xray + sing-box 双内核，约 15 种协议，全部代码明文开源。

> **当前状态：阶段 1 的代码已写完，但还没有在真实服务器上安装验证过。** 目前只通过了不碰系统的本机测试（状态、冲突、渲染、节点输出）。仓库地址仍是占位符。详见[开发路线](docs/09-开发路线.md)里的"阶段 1 的实现状态"。

## 三步上手

1. 准备一台 VPS（Debian、Ubuntu 或 Alpine），用 SSH 以 root 登录。
2. 运行安装命令：

   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/<用户名>/<仓库名>/main/install.sh)
   ```

3. 一路回车。安装结束后，把屏幕上的链接或二维码导入手机、电脑上的客户端。

之后随时输入 `pbox` 打开菜单。**连不上时先选菜单里的"体检"。**

不放心直接运行远程脚本？可以先下载、打开看一眼，再执行：

```bash
curl -fsSLO https://raw.githubusercontent.com/<用户名>/<仓库名>/main/install.sh
```

```bash
bash install.sh
```

## 它和别的脚本有什么不同

| | |
|---|---|
| 不用做选择 | 默认方案不需要域名、不需要懂协议，回车即可 |
| 会告诉你哪里冲突 | 两个协议抢同一个端口或互相矛盾时，脚本用人话说明并让你取舍 |
| 连不上能自查 | "体检"逐项检查并给出下一步怎么做 |
| 升级不翻车 | 新配置先校验，失败自动回到上一份能用的 |
| 不乱动系统 | 不擅自安装或替换防火墙，不碰已有网站，卸载不留残留 |
| 不收集任何信息 | 零遥测，不经过任何第三方订阅转换 |
| 不夹带私货 | 没有推广链接，不悄悄屏蔽网站，不依赖作者自己的服务器 |

## 开发

源码在 `src/`，按模块拆分。合并成单文件：

```bash
./build.sh
```

运行不需要 root、不碰系统的测试：

```bash
bash tests/run.sh
```

真机测试会真的安装内核、创建服务和账号，最后卸载。只在可以随时重装的测试机上运行：

```bash
sudo bash tests/vm.sh
```

推送到 GitHub 后，`.github/workflows/ci.yml` 会自动跑三组检查：静态检查与本机测试；在带 systemd 的 Ubuntu 虚拟机（含 ARM）上完整地装一遍再卸掉；在 Debian 和 Alpine 容器里验证下载、哈希和内核对配置的校验。

产物是 `dist/pbox.sh`。在一台全新的测试机上可以直接运行它来安装：

```bash
bash dist/pbox.sh install
```

## 说明

- 名称 pbox 取自 proxy box：一个装好就能用的代理盒子。
- 请遵守你所在地的法律法规和 VPS 服务商的使用条款。
