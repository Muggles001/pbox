# 术语表

按"第一次搭节点会遇到的顺序"排列。

## 基础

| 词 | 意思 |
|---|---|
| VPS | 租来的一台远程电脑，一直开机联网。节点就装在它上面 |
| SSH | 从自己电脑登录 VPS 的方式，登录后看到的是一个只能打字的黑窗口 |
| root | VPS 上权限最高的账号。安装脚本需要用它运行 |
| 客户端 | 装在手机、电脑上的代理软件，例如 v2rayN、sing-box、Mihomo（Clash）、Shadowrocket |
| 节点 | 一条连接信息，告诉客户端"连哪台服务器、用什么方式连" |
| 分享链接 | 把节点信息压缩成的一行文字，以 `vless://`、`hysteria2://` 等开头，复制到客户端即可导入 |
| 订阅 | 一个网址，客户端定期访问它来自动更新节点列表 |

## 脚本相关

| 词 | 意思 |
|---|---|
| 内核 | 真正负责转发流量的程序。本脚本用到两个：Xray 和 sing-box。脚本只是帮你安装和配置它们 |
| 协议 | 客户端和服务器之间约定的通信方式。不同协议在速度、隐蔽性上各有长短 |
| 配置文件 | 内核读取的设置。本脚本自动生成，不需要手改 |
| 体检 | 脚本里的自查功能，逐项检查哪里出了问题 |

## 网络

| 词 | 意思 |
|---|---|
| 端口 | 一台服务器上的"门牌号"，范围 1 到 65535。每个协议要占一个 |
| TCP / UDP | 两种传输方式。TCP 稳，UDP 快但更容易被运营商限速。同一个端口号的 TCP 和 UDP 互不影响 |
| 443 端口 | 正常网站加密访问用的端口。代理用它最不显眼，所以抢手 |
| 防火墙 | VPS 系统里决定哪些端口允许外面访问的开关 |
| 安全组 | 云厂商网页后台里的另一层防火墙。**它不在 VPS 里，脚本管不到，需要你自己去网页上放行端口** |
| IPv4 / IPv6 | 两代 IP 地址。IPv4 形如 `1.2.3.4`，IPv6 形如 `2001:db8::1` |
| 双栈 | 一台机器同时有 IPv4 和 IPv6 地址 |

## 域名与证书

| 词 | 意思 |
|---|---|
| 域名 | 形如 `example.com` 的网址。部分协议需要，默认方案不需要 |
| A 记录 / AAAA 记录 | 域名指向 IPv4 地址的设置叫 A 记录，指向 IPv6 的叫 AAAA 记录 |
| 证书 | 证明"这个域名确实是我的"的文件，加密连接要用 |
| 自签证书 | 自己给自己发的证书。不需要域名，但客户端默认不信任它 |
| ACME | 自动免费申请正规证书的机制 |
| CDN | 挡在你服务器前面的大型中转网络，常用的是 Cloudflare。套上之后别人看不到你的真实 IP |

## 伪装与封锁

| 词 | 意思 |
|---|---|
| 伪装 | 让代理流量看起来像普通的网站访问 |
| Reality | 一种不需要自己域名的伪装技术：让你的服务器在外人看来像是某个知名网站 |
| 伪装域名（SNI） | Reality 冒充的那个网站域名 |
| 主动探测 | 审查方主动连接你的服务器，试探它是不是代理 |
| 端口被封 | 只有某一个端口从国内连不上，换端口即可恢复 |
| IP 被墙 | 整个 IP 从国内都连不上，需要套 CDN、走隧道或换 IP |
| 端口跳跃 | Hysteria2 的功能：在一段端口范围内不断切换，缓解单个端口被限速 |
| Argo 隧道 | Cloudflare 提供的隧道。服务器主动连出去，不需要开放任何端口，IP 被墙时也能用 |

## 出口

| 词 | 意思 |
|---|---|
| 出口 | 服务器访问目标网站时使用的地址。网站看到的是这个地址 |
| 分流 | 让不同网站走不同出口 |
| WARP | Cloudflare 提供的免费出口。常用来解决"目标网站不欢迎 VPS 的 IP"的问题 |
| 中转 / 落地 | 两台服务器接力：你连中转机，中转机再连落地机，最后由落地机访问网站 |
| BBR | 一种让 TCP 在丢包线路上更快的系统设置 |
