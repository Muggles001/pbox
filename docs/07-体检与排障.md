# 体检与排障

## 一、先做体检

连不上、变慢、突然断了，第一步都是：

```bash
pbox doctor
```

或在菜单里选"体检"。输出示例：

```
体检  5/7 通过

  ✓ 内核运行中
  ✓ 配置有效
  ✓ 端口已监听        TCP 443 · UDP 443
  ✗ 系统防火墙        UDP 443 未放行
      → 输入 y 由脚本放行，或手动执行：ufw allow 443/udp
  ✓ 系统时间准确
  ✓ 伪装目标可用
  ! 外部可达性        服务器无法自行判断，请按下方步骤在自己电脑上测试
```

## 二、体检项

| 检查 | 方法 | 不通过时脚本怎么做 |
|---|---|---|
| 内核是否运行 | 查服务状态 | 显示最近的错误日志，提供"重启"和"回滚到上一份配置" |
| 配置是否有效 | 用内核自带的校验命令 | 指出出错的协议，提供回滚 |
| 端口是否在监听 | 查本机监听列表 | 指出被谁占用，提供换端口 |
| 系统防火墙 | 识别 ufw、firewalld、nftables、iptables 中已启用的那个 | 询问是否放行；不同意则给出手动命令。**脚本不会安装或替换防火墙** |
| 系统时间 | 与公共网站返回的时间比对 | 偏差过大时提示开启时间同步。部分协议对时间敏感 |
| 证书 | 检查有效期与域名是否匹配 | 临近过期提示续期，续期失败给出原因 |
| Reality 伪装目标 | 实测目标网站是否仍可用 | 提供重新挑选 |
| 出口连通 | 从服务器访问外网，IPv4、IPv6 分别测 | 指出哪一栈不通，对应节点标记为不可用 |
| 资源 | 内存、磁盘余量 | 余量过低时提示 |
| SSH 登录方式 | 是否允许用密码登录 | 只提醒：弱密码的服务器容易被入侵并被当作跳板，建议改用密钥。脚本不修改 SSH 设置 |
| 域名解析 | 域名模式下核对解析是否指向本机，是否误开 CDN | 指出哪条记录不对 |
| 外部可达性 | 见下一节 | — |

## 三、外部可达性：需要你在自己电脑上测

服务器无法知道"从你家里能不能连到它"。体检会生成一条已经填好地址和端口的命令，复制到自己电脑上运行，一次测完所有 TCP 端口。单个端口的写法如下：

Windows（PowerShell）：

```powershell
Test-NetConnection 1.2.3.4 -Port 443
```

macOS、Linux：

```bash
nc -vz 1.2.3.4 443
```

这只能测 TCP。UDP 协议（Hysteria2、TUIC）没有简单的测法，以客户端能否连上为准。

## 四、四种故障，四种处理

| 现象 | 判断 | 处理 |
|---|---|---|
| 体检有 ✗ | 服务器自身问题 | 按体检给出的步骤修 |
| 体检全过，本地测 TCP 端口不通，换个端口就通 | 端口被封，或云厂商安全组没放行 | 先查安全组；确认已放行则在"设置"里换端口 |
| 体检全过，本地测所有端口都不通，但海外网络能连上 | IP 被墙 | 改用 Argo 隧道或套 CDN 的节点；或向 VPS 商更换 IP |
| 体检全过，本地测端口通，客户端仍连不上 | 客户端一侧的问题 | 重新导入最新链接；核对客户端版本是否支持该协议；核对手机、电脑时间 |

## 五、常见问题

**刚装完就连不上**

九成是云厂商安全组没放行。安装结束那一屏最后一行列出了需要放行的端口，去 VPS 商的网页后台添加。

**用了一段时间突然连不上**

依次做：体检 → 本地测端口 → 对照上面的表。如果只有 UDP 节点不通而 TCP 节点正常，多半是运营商在限制 UDP，先用 TCP 节点。

**晚上很慢**

通常是线路拥堵，不是配置问题。可以试试切换 TCP 和 UDP 节点，或开启 BBR。Hysteria2 的端口跳跃对部分运营商有帮助，对另一些没有，不保证有效。

**IPv6 节点连不上**

很多家庭和移动网络的 IPv6 并不稳定。用 IPv4 节点即可，这也是默认把两者分开输出的原因。

**更新后出问题**

脚本更新时会保留上一份能用的配置和内核。体检里选"回滚"即可恢复。

**能连上，但某些网站打不开或要求验证**

这是目标网站不欢迎 VPS 的 IP，和过墙无关。可以在"出口与分流"里让这些网站走 WARP。

**想换一台 VPS**

旧机器上"备份"导出，新机器上安装后"恢复"导入。IP 变了，脚本会重新生成链接。

## 六、求助时请带上

```bash
pbox doctor --report
```

它生成一份已隐去 IP、域名、密钥的报告，可以直接贴到 issue 里。
