# 痛点依据

每项设计对应的用户反馈来源。整理于 2026-11-09。

## 调研范围与局限

- 主要来源是两个参考仓库的 issue 列表：mack-a/v2ray-agent 当时的全部开放 issue（22 条），yonggekkk/sing-box-yg 已关闭 issue 的第一页（25 条，共 285 条）。
- 辅以一个 V2EX 帖子和 sing-box 官方迁移文档。
- NodeSeek 等论坛页面无法抓取，论坛侧的样本偏少。结论偏向"会去 GitHub 提 issue 的用户"，纯新手在论坛和群里的抱怨覆盖不足。

## 痛点与设计对照

下表中 mack-a 指 mack-a/v2ray-agent，yg 指 yonggekkk/sing-box-yg。

| 痛点 | 依据 | 对应设计 | 文档 |
|---|---|---|---|
| 内核升级后配置报错、协议失效 | yg #352 "很多协议无法使用了"、#351 "reality和anytls不通了"、#345 生成的配置运行不起来；sing-box 在 1.11、1.12、1.14 均有破坏性变更 | 内核版本锁定；模板随版本；校验失败自动回滚 | [技术架构](08-技术架构.md) |
| 证书申请、续期失败 | yg #326 "证书自动续期失败"、#328 认为 acme 成功率不高 | 默认方案不需要域名；域名模式申请前预检 | [设计总览](01-设计总览.md) |
| 装完连不上，不知道错在哪 | yg #347 "新服务器链接不上"、#338 部分网站无法访问；mack-a #1367 节点测试 -1 | 体检；四种故障的判断表 | [体检与排障](07-体检与排障.md) |
| 改一个参数要重装 | mack-a #1261 如何修改 443 端口、#1317 建议单独更换域名 | 端口、伪装目标、密钥均可单独修改 | [安装与菜单](04-安装与菜单.md) |
| 没有备份、迁移 | mack-a #1265 建议导入导出、#1240 一键备份恢复 | 状态目录即全部；加密导出与导入 | [技术架构](08-技术架构.md) |
| 脚本破坏系统原有组件 | mack-a #1289 安装 iptables-persistent 导致 ufw 被卸载 | 不安装、不替换防火墙；端口跳跃规则由自己的服务恢复 | [技术架构](08-技术架构.md) |
| 两个内核互相删除 | mack-a #1371 安装 Xray 和 sing-box 时互相删除服务 | 两个内核各自独立的目录与服务 | [技术架构](08-技术架构.md) |
| CDN 域名与直连域名混用 | mack-a #1335 建议把 CDN 协议的域名与其他协议分开 | 硬冲突 H5 | [冲突规则](03-冲突规则.md) |
| 与现有网站冲突 | mack-a #1255 能否支持现有网站配置 | 检测到已有网站不接管；硬冲突 H8 | [冲突规则](03-冲突规则.md) |
| 屏蔽规则导致断网 | mack-a #1274 添加国内黑名单后无法联网 | 硬冲突 H11；屏蔽项为可选并说明影响 | [隐私与安全](05-隐私与安全.md) |
| IPv6、双栈下节点不通 | mack-a #1355 订阅未考虑客户端 IPv6 不可用、#1182 中转机无法解析 IPv6 网站 | 节点地址模式默认分开；客户端配置默认优先 IPv4 | [安装与菜单](04-安装与菜单.md) |
| 系统优化重启后失效 | yg #333 重启后 BBR 变回 cubic | 写入独立的系统设置文件 | [技术架构](08-技术架构.md) |
| UDP 被限速，端口跳跃未必有效 | V2EX 用户反馈：电信家宽周期性断 UDP，开 3000 个端口跳跃无效，疑似按 IP 统计 | 默认同时提供 TCP 与 UDP 节点；端口跳跃为可选且不承诺效果 | [伪装与抗封锁](06-伪装与抗封锁.md) |
| WARP 分流不稳定 | yg #342 访问规则内网站时不时断连、#346 如何换 WARP 的 IP | 明确 WARP 只是出口手段；放在阶段 4 单独打磨 | [伪装与抗封锁](06-伪装与抗封锁.md) |
| 依赖工具引发的报错 | yg #324 jq 解析错误；mack-a #1334 jq 参数过长 | 不依赖 jq，配置整份渲染 | [技术架构](08-技术架构.md) |
| 小内存机器部署困难 | yg #339 关于小鸡服务器的部署问题 | 内核按需安装；依赖最小化 | [设计总览](01-设计总览.md) |
| Hysteria2 缺少混淆选项 | yg #334 希望支持混淆密码 | Salamander 混淆作为可选项；硬冲突 H6 | [冲突规则](03-冲突规则.md) |
| 希望支持 ECH | mack-a #1269 | CDN 模式的进阶选项 | [伪装与抗封锁](06-伪装与抗封锁.md) |
| 系统支持不全 | mack-a #1352 Amazon Linux 不支持 | 阶段 4 扩展到 RHEL 系 | [开发路线](09-开发路线.md) |
| 想加入自己的配置 | mack-a #1254 能否支持自定义模板 | `custom/` 目录，由内核合并加载并一同校验 | [技术架构](08-技术架构.md) |

## 未采纳的需求

| 需求 | 来源 | 不采纳的原因 |
|---|---|---|
| 订阅流量限额、流量统计 | mack-a #1214；yg #343 | 需要常驻统计与对外接口，与隐私优先和最小暴露面冲突。待阶段 4 后再评估 |
| 增加 SSR 协议 | yg #325 | 协议已过时，两个内核都不支持 |
| Docker 部署 | yg #321；mack-a #1311 | 当前聚焦直接安装；容器化会带来另一套网络与持久化问题 |
| Psiphon、VPNGate 分流 | yg #349、#335 | 稳定性反馈差 |
